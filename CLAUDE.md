# ZoulettesTCG

React + Vite SPA. Single file: `src/App.jsx`. SVG card template: `public/Card_TCG.svg`.

Stack: React 18, Vite 5, vanilla CSS-in-JS, localStorage.

Card model: `BLANK` object. SVG viewBox: 616.5×841.5. Scale via `VW`/`VH` constants.
